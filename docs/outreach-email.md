# 燃稿 · Outreach Email 模板

## 目标客户
- 学术公众号运营者（材料/化学/生医期刊解读类）
- 期刊编辑部宣传人员
- 高校/研究所科研宣传岗

## 模板 A：冷启动 outreach（给公众号运营者）

**Subject**: 你周日晚上还在赶公众号稿子吗？

---

XX老师/同学你好，

我是燃稿的作者。之前看到你们公众号「XX」的文章，解读风格很有特色。

我知道你们一篇论文解读可能要花 4-6 个小时：下 PDF、读论文、写稿、配图、调 HTML、上传素材、复制粘贴到微信后台。周日晚上还在赶周一的推送。

我写了一个工具叫**燃稿（RánGǎo）**，把整个流程压缩成一条命令：

```
输入 DOI → 自动下载论文 → AI 按你的风格写稿 → 生成微信 HTML → 推送到草稿箱
```

昨天用一篇 Advanced Materials 论文实测：**59 秒**，出了一篇 5000 字的文章，红色方块标题、虚线图片边框、关键词着色全部自动生成，可以直接复制到微信后台。

对比一下：

| | 手动 | 燃稿 |
|---|---|---|
| 耗时 | 4-6 小时 | 1 分钟 |
| HTML 排版 | 反复调试 | 一次生成 |
| 图片上传 | 逐张手动 | 自动上传 CDN |
| 风格一致性 | 靠记忆 | 靠模板（YAML 可编辑） |

开源：https://github.com/SpencerRaw/rangao  
你只要有 DeepSeek API Key（¥2/篇），就能免费使用。

如果你愿意试一下，把一篇论文的 PDF 或 DOI 发给我，我给你跑一版看看效果。你觉得风格哪里不对，我帮你调模板。

--
Yiwei

## 模板 B：给期刊编辑部

**Subject**: 你们每期新论文的公众号推广，可以自动化了

---

XX编辑您好，

我是燃稿的作者。期刊编辑部有一个重复劳动：新一期论文出来 → 挑亮点文章 → 写中文解读 → 排版 → 发公众号。每篇文章都要人工处理。

燃稿可以做这件事：**输入 DOI，输出微信草稿**。

工作流程：
1. 从 Crossref 自动抓取你们期刊最新论文
2. 按你定义的写作风格生成中文解读
3. 生成微信兼容的 HTML（内联样式，无需手工调）
4. 自动上传图片到微信素材库
5. 推送到草稿箱，编辑审核后发布

上个月，Advanced Materials 的论文实测：输入论文 PDF，59 秒出了 5000 字的解读文章。附上效果：[截图/链接]
